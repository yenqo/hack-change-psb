## Решения по бэклогу

- **B3 подтверждён пользователем (10.11.2026).** v1.3 не меняется. Исправление B3 — отдельный эксперимент сразу перед 7.1, чтобы 7.1 мерился на исправленной проверке чисел. Масштаб оценить без новых вызовов: на ответах калибровочных прогонов офлайн прогнать старую и исправленную проверку чисел и посчитать, на скольких ответах B3 давал ложное «неподтверждённое число», сколько из-за этого было вызовов исправления и удалённых предложений.
- **B3 реализован за флагом `SOLUTION_FIX_DOCNUM` (10.11.2026)** вместе с 7.6 и 7.1 — разовый обход протокола; замер — при получении golden set (см. «Отложенная валидация» в [experiments.md](experiments.md)). Офлайн-оценка масштаба — `tools/b3_impact.py`.
- **B5 реализован за флагом `SOLUTION_SOFT_DEGRADE` (10.11.2026)**, проверен на заглушке со сбоями — см. журнал экспериментов.
- **B2 / R5 (11.11.2026):** частота на 222 сохранённых ответах — 0 противоречий «Да/Нет» ↔ обоснование. Исправление (правка промпта, затем самопроверка) отложено до golden set: `tools/diagnose.py`, раздел «(г)», покажет частоту на нём.
- **B13 / R6 (11.11.2026):** отсылки внутри законов реализованы за флагом `SOLUTION_CROSS_REFS` (выключен), замер — `eval/reports/2026-11-11_R6.md`: на демо и 12 сценариях цели отсылок уже в контексте, эффекта сверх шума нет. Вернуться, если R1 на golden set покажет вопросы, где нужный пункт не попал в контекст; вариант R6b — без строк «нет в базе», добавлять пункт, только когда цели нет в контексте. Попросить продактов добавить 3–5 вопросов по подпунктам НК 164 / 284 и по 152-ФЗ.
- **12.11.2026: B14, B15 добавлены; приоритет по ожидаемому эффекту — B14 → B15 → B10 / B11.** Эффекты, вероятно, 1–5 баллов — меньше шума платформы (~5), поэтому решения — по локальному парному замеру и golden set, сабмит — только при большом локальном эффекте.
- **12.11.2026: ретривер.** По замерам (R1, R6, R7) поиск — не узкое место: на демо нужное в контексте в 51 из 51 ответа. Известные слабые места — B12, B16, B17, B18 (родительский пункт для больших статей); крупно не дорабатывать, пока `tools/diagnose.py` на golden set не покажет вопросы, где нужный пункт не попал в контекст.
