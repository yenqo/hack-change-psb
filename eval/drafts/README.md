# Черновики агента — НЕ ДЛЯ ЗАМЕРОВ

`agent_questions_DRAFT.csv` — 72 вопроса с эталонами, которые составил ИИ-агент до того, как было решено, что golden set
составляют продакты команды. **Это черновик агента, не для замеров:** ни один из этих вопросов не входит в golden set
и не используется в решениях по доработкам.

Продакты могут взять отсюда идеи формулировок и ловушек. Перед включением в golden set каждый вопрос и эталон
нужно проверить по базе по правилам [docs/golden_guide.md](../../docs/golden_guide.md) и прогнать
`tools/check_golden.py`. Колонка `split` намеренно пустая.
